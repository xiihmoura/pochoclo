Backup e restauração

Os dados ficam neste navegador. Faça backups frequentes para não perder informações ao trocar de computador ou limpar os dados do navegador.

Para usar em mais de um dispositivo ou compartilhar dados, será necessário hospedar o sistema e conectar um banco de dados com autenticação. Esta versão funciona localmente neste navegador.
